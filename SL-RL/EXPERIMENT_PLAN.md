# exp1 실험 계획

**질문**　1vs1에서 지도와 정책을 배운 에이전트 세 명을 한 팀에 놓으면, 처음부터 3vs3에서 배운 팀만큼 영역을 확보하고 이길 수 있는가?

두 모델은 프로젝트에서 약한 상대와 중간 난도 상대의 후보입니다. 실제 난도는 고정 상대 및 직접 맞대결 성적으로 판정합니다.

## 순서

1. `verify.py`로 원본 연결, 진영 변환, 시작 행 균형, 점령 보상, 사망·부활, 64틱 종료, 이어학습 재현, 평가 양식을 점검합니다.
2. 1vs1·3vs3에서 인코더를 따로 학습합니다. 두 조건의 지도 표본 수·마스크·네트워크 폭·학습량을 맞춥니다. fit별 검증 손실과 전체·전선 정확도를 초기 지도·이웃 다수결과 비교합니다. 전선에서 개선이 작다면 기록하고 후속 실험에서 표집량이나 마스킹 방식을 검토합니다.
3. 인원 조건별 인코더를 고정하고 7, 19, 31 시드마다 1vs1과 3vs3을 학습합니다. 양 팀 모두 학습하며 경기 수·보상·틱·PPO 설정을 맞춥니다. 기준 설정은 6개 run, 각 3,200경기입니다. 최근 체크포인트로 고정 상대를 평가하고 마지막 본 비교에는 동일한 학습 경기 수의 체크포인트를 사용합니다.
4. 각 run에서 양 팀을 각각 3vs3 환경의 random·expand·aggressive·defend·noop와 경기시킵니다. 상대당 40경기는 해당 학습 팀 기준으로 진영당 20경기입니다. 같은 시드의 두 run을 직접 맞붙일 때는 학습 진영 조합당 40경기입니다. 기본 설정의 고정 상대 평가는 총 2,400경기, 맞대결은 총 480경기입니다.
5. 결과표에는 학습 인원, 시드, 학습 팀, 상대, 실제 진영, 경기 수, 승·무·패, 최종 점령 격차, 에이전트당 보상, 승률을 기재합니다. CSV의 승률은 승수/전체 경기 수이며 무승부는 별도로 셉니다. 진영별 상세 표의 원자료는 `games.csv`에 있습니다.

## 결과를 어떻게 읽을까

- 먼저 같은 학습 시드의 맞대결 승패와 최종 격차를 확인하고 세 시드 중 몇 개에서 같은 경향인지 적습니다. 한 run 안의 빨강·파랑 팀은 자기대전 상대였으므로 독립적인 훈련 시드로 세지 않습니다.
- 상대별로 두 모델의 차이를 봅니다. noop 성적은 기본 점령 능력을 확인하는 용도입니다. expand를 이기는 능력, aggressive의 직접 공격을 견디는 능력, defend가 점유한 전선을 바꾸는 능력은 다를 수 있습니다.
- 훈련 CSV에서는 실제 환경 틱, 선택 가능한 행동이 있었던 에이전트 수, 업데이트 수를 성능과 함께 봅니다. 3vs3은 같은 경기 수에서도 정책이 처리한 개별 행동 표본이 더 많습니다. `environment_ticks`는 양 팀 행에 중복 기록되므로 한 경기 예산을 셀 때 한 팀의 값만 합산합니다.
- `frontier` 3×10은 세 행 모두에서 시작하므로 3vs3의 초기 배치는 동일합니다. 평가는 정책·상대·부활 등의 변동을 포함하며, 다른 시작 배치에 대한 일반화는 이번 결론의 범위 밖입니다. greedy 정책과 noop 등으로 실제 궤적이 반복되면 40경기의 결과가 비슷할 수 있습니다.
- 성능 차이에는 인원별 사전학습 지도 분포와 PPO 학습 환경의 효과가 함께 들어갑니다. 팀 협력의 단독 효과나 SSL의 단독 효과를 주장하려면 추가 대조가 필요합니다.
