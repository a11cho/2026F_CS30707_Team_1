# exp4 · expand와 aggressive 혼합 교사학습

시드당 하나의 3대3 모델을 만듭니다. exp2의 같은 시드 raw PPO에서 시작하며, 기존처럼 빨강·파랑은 각각 팀 정책 하나를 가지고 각 팀원 셋이 이를 공유합니다. 두 정책 모두 두 교사의 시범을 함께 배웁니다.

## 저장소 루트에서 실행

```text
python -B SL-RL/experiment/exp4/exp4.py train
python -B SL-RL/experiment/exp4/exp4.py plots
python -B SL-RL/experiment/exp4/exp4.py evaluate
```

첫 줄은 Windows에서 rlTeam의 현재 Python을 사용해 시드별 콘솔 세 개를 엽니다. 처음 실행 시 exp4/run1·run2·run3을 할당하고 각 settings.json에 시드·기준 체크포인트 경로·해시를 기록합니다. 중단 후 같은 명령으로 마지막 완료 epoch부터 이어갑니다. 완료된 시드는 건너뜁니다. 학습 설정이 달라지면 새 run을 할당합니다. 입력 파일만 확인하려면 train 대신 plan을 사용하세요.

## 데이터와 학습

- 기준은 exp2 최종 PPO 업데이트 400의 raw 3대3 정책입니다. 시드 7·19·31은 각각 run12·run11·run10입니다. 지도·틱·모델 구조는 각 기준 체크포인트에서 복원합니다.
- 매 시범 경기는 expand 팀과 aggressive 팀의 대결입니다. 경기마다 진영을 교대하고 여섯 에이전트의 실제 선택 직전 학생 입력과 교사 행동을 짝지어 양 진영을 공통 방향으로 변환합니다. 사망 등 행동 선택지가 하나뿐인 표본을 제외합니다. 학생에게 교사 ID를 주지 않습니다.
- 기본값은 시드당 학습 160경기, 별도 검증 32경기, 24에포크, 배치 256, 학습률 0.0003입니다. 데이터를 한 번 수집해 반복 학습하며 재개 시 같은 시드로 복원합니다. 마스킹된 행동분포의 음의 로그우도를 줄이며, 표본 수에 관계없이 두 교사의 전체 손실 기여도를 1:1로 맞춥니다.
- actor와 개체 특징 추출 층을 업데이트합니다. critic 헤드는 고정하며 PPO 보상 업데이트는 하지 않습니다. 학습 손실과 검증 손실은 두 교사 평균입니다. 검증 일치율은 선생님이 실제 선택한 행동과 학생 최빈 행동이 같은 비율입니다. 같은 상황에서도 교사가 동점 행동을 무작위로 선택할 수 있습니다.
- before.pt는 초기 정책, latest.pt는 이어학습, best.pt는 학습한 에포크 중 두 진영 평균 검증 손실이 최소인 정책입니다. training.csv에 에포크별 손실과 교사별 검증 일치율을 보관합니다.

## 결과 읽기

plots는 result/learning_run…/learning.png를 만듭니다. evaluate는 학습 전과 best를 같은 평가 시드·진영·봇 조건으로 직접 대전시킵니다. 기본값은 학습된 진영 정책 하나와 상대 하나당 40경기(실제 진영별 20경기)입니다. 시드 하나에서 상대별·학습 전후 각각 80경기를 평가합니다. 상대는 expand와 aggressive입니다. 경기 수와 평가 시드는 config.toml에서 바꿀 수 있습니다.

result/evaluation1, evaluation2, …에 시드별·전체 승무패와 승률 변화(%p)를 담은 win_rates.csv, 그래프 win_rates.png, 경기 원자료 위치 sources.json이 생성됩니다. 각 run의 evaluation/eval번호에 경기별 CSV가 남습니다. 필요할 때만 evaluate 뒤에 --trace-all을 붙여 전체 틱과 협력 지표를 저장하세요. 행동 모방이 잘 되었는지는 검증 일치율로, 실전 개선은 같은 상대에 대한 전후 승률로 판정합니다.
