# exp2 · 마스킹 없는 AE와 원본 지도의 PPO 비교

저장소 루트에서 `rlTeam`을 활성화한 CMD 또는 PowerShell로 아래 한 줄을 실행합니다.

```text
python -B SL-RL/experiment/exp2/launch.py
```

현재 터미널에서 1대1과 3대3의 AE를 한 번씩 준비하고, 같은 Python을 쓰는 **새 Windows 콘솔 세 개**를 엽니다. 콘솔마다 시드 하나(7, 19, 31)를 맡아 아래 네 조건을 위에서부터 순서대로 실행합니다. 부모 터미널에는 전체 완료 여부가 표시됩니다. 실행 중에는 열어 두세요. [실행 명령을 구성하는 파일](launch.py) · [공통 설정](config.toml)

| 콘솔당 순서 | 지도 입력 | 자기대전과 학습 중 검증 | PPO 학습 경기 |
|---|---|---|---:|
| 1 | AE · 고정 16차원 | 1대1 | 3,200 |
| 2 | AE · 고정 16차원 | 3대3 | 3,200 |
| 3 | 원본 · 30칸 | 1대1 | 3,200 |
| 4 | 원본 · 30칸 | 3대3 | 3,200 |

PPO 예산은 400업데이트 × 8경기 × 12개 run으로 총 38,400경기입니다. 맵 3×10, 최대 64틱, 보상 계수 α=1과 PPO 최적화 설정은 exp1과 같습니다. 각 팀은 팀 안에서 정책을 공유하고 양 팀은 자기대전 경험으로 각자의 파라미터를 업데이트합니다.

### 사전학습과 입력

AE의 입력과 정답은 동일한 30칸의 이진 소유권 지도입니다. 한 칸은 아군 또는 상대 소유입니다. 유닛 위치·상태는 기존의 별도 개체 입력을 사용합니다. exp1과 동일한 인코더 구조에서 마스크 채널은 모두 0이고, 전체 30칸의 이진 교차엔트로피를 최소화합니다. 인원별 160경기를 학습 128경기와 검증 32경기로 나누고 한 경기당 12시점에서 양 진영의 지도를 수집합니다. 30에포크 중 전체 칸 검증 손실이 가장 낮은 인코더를 고정해 같은 인원의 세 시드에 사용합니다. 여기서 전체 칸 정확도는 마스킹된 칸만 채점했던 exp1과 채점 대상이 다릅니다.

원본 조건은 같은 관점의 30칸 지도 값을 직접 PPO에 넣습니다. 다른 상태 입력, 보상 및 자기대전 규칙은 같습니다. 지도 입력 폭이 16에서 30으로 늘어나므로 actor와 critic의 첫 층 파라미터 수도 달라집니다.

### 검증·저장·이어학습

- `ppo.checkpoint_every = 20`이므로 160 학습 경기마다 그리고 마지막 업데이트에서 검증합니다. 1대1 학습 팀은 1대1에서, 3대3 학습 팀은 3대3에서 검증합니다.
- 양쪽 학습 정책 각각이 random, expand, aggressive, defend와 6경기씩 치릅니다. 3개 고정 경기 시드에 양 진영을 짝짓고, 1대1은 위·가운데·아래 행을 모두 사용합니다. 후보당 48경기, 기본 예산에서 run당 검증 960경기입니다. 검증 경험은 PPO 업데이트에 넣지 않습니다.
- 각 run에 최신 시점 `latest.pt`, 검증 점수 `(승 + 0.5 × 무) / 경기 수`가 가장 높은 시점 `best.pt` 두 개를 보관합니다. 동점이면 더 늦은 시점을 택합니다. 두 파일 모두 양 팀 정책·옵티마이저·난수 상태를 포함합니다. AE 자체의 최고 에포크는 별도로 사전학습 폴더의 `encoder.pt`에 저장합니다.
- 같은 일괄 명령을 다시 실행하면 설정이 일치하는 완료 AE는 재사용하고 기존 run은 마지막 저장 시점부터 이어갑니다. 목표에 도달한 run은 추가 학습 없이 확인을 마칩니다. 첫 체크포인트 이전에 중단한 run은 같은 시드·폴더에서 다시 시작합니다. 새 조건 비교에는 새 실험 폴더를 사용하세요.
- 세 콘솔이 번호를 나누어 쓰므로 `run1`부터 `run12`의 배정 순서는 달라질 수 있습니다. 각 run의 `settings.json`에 `config.representation`, `size`, `seed`, 인코더 경로가 있습니다. `training.csv`에는 학습 팀별 PPO 지표, `validation.csv`에는 검증 시점별 승·무·패와 점수가 있습니다. `latest.pt`에 저장된 검증 이력으로 중단 시 CSV와 최고 모델 저장을 마무리합니다.

실행 예정 명령만 확인할 때는 다음 명령을 사용합니다.

```text
python -B SL-RL/experiment/exp2/launch.py --plan
```

### 학습 후 결과 확인

아래 명령은 최종 400번째 업데이트 기준입니다. 양 학습 정책을 **3대3** 고정 상대 5종과 평가하고 같은 입력 방식·시드끼리 1대1 복제 팀과 3대3 직접 학습 팀을 맞붙입니다. 최종 평가용 경기 시드와 검증용 경기 시드를 분리합니다.

```text
python -B SL-RL/analysis.py plots --experiment exp2
python -B SL-RL/analysis.py evaluate --experiment exp2
python -B SL-RL/analysis.py report --experiment exp2
python -B SL-RL/analysis.py replays --experiment exp2
```

그림과 보고서의 기준 폴더는 `experiment/exp2/result/analysis_u0400/ae/`와 `raw/`입니다. 개별 run의 최고 시점도 예를 들어 `python -B SL-RL/run.py evaluate --experiment exp2 --run run1 --checkpoint best.pt`로 평가할 수 있습니다. 1대1 정책은 동일한 가중치를 각 에이전트에 적용해 3대3으로 전이합니다.

축소 검증은 `python -B SL-RL/experiment/exp2/verify.py`로 재현할 수 있습니다. 임시 실험에서 최대 4틱·조건당 2경기로 실제 세 콘솔과 12가지 조합, 체크포인트 선택·재개, 평가·보고서를 검사합니다.
