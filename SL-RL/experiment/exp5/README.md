# exp5 · 네트워크 크기와 고정 봇 상대 승률

저장소 루트의 rlTeam 터미널에서 실행합니다.

```text
python -B SL-RL/experiment/exp5/exp5.py plan
python -B SL-RL/experiment/exp5/exp5.py train
python -B SL-RL/experiment/exp5/exp5.py plots
python -B SL-RL/experiment/exp5/exp5.py evaluate
```

plan은 확인용입니다. train은 Windows에서 시드별 터미널 3개를 열고 한 터미널이 세 구조를 순차 실행합니다. 원래 터미널을 열어 두세요. 중단 뒤 같은 명령으로 마지막 저장점부터 재개합니다. 기존 설정과 다른 학습 조건은 새 run을 받습니다. 경로와 시드·구조 매핑은 각 run의 settings.json에 저장됩니다.

## 무엇을 비교하나요?

3×10, 64틱 raw 3대3 환경에서 빨강·파랑은 각각 별도 팀 정책을 사용합니다. 두 헤드의 폭을 함께 [128], [64,64], [128,128]로 바꾸고 개체 임베딩 32차원과 Tanh는 유지합니다. 팀당 파라미터 수는 각각 19,434개, 18,154개, 52,458개입니다. 모든 구조가 동일한 시드와 PyTorch Linear 기본 초기화 규칙에서 출발합니다. 구조가 달라지면 개별 가중치 값도 달라집니다.

1. 기존 exp2 방식으로 자기대전 PPO+GAE 400업데이트 × 8경기를 수행합니다. 틱 보상은 팀 점유율 + 개인 점령 기여입니다. [128]은 모델·시드·환경·PPO 설정·최종 업데이트가 일치하는 exp2 raw 체크포인트가 있으면 그대로 재사용합니다. pretrained.pt의 source에 출처가 남습니다. 없거나 재사용을 끄면 같은 방식으로 새로 학습합니다. 깊은 구조는 각자의 가중치를 학습합니다.
2. 사전학습된 actor·critic 전체를 이어받고 Adam 상태를 새로 시작합니다. 새 단계는 400업데이트 × 8경기이고, 네 경기마다 두 학습 팀이 두 고정 봇을 한 번씩 만납니다. 한 경기에서 학생 쪽 세 명만 PPO로 업데이트할 경험을 냅니다. 시드·구조당 총 3,200경기, 각 진영 정책당 각 봇 800경기입니다.
3. 학생 팀원 셋의 보상은 동일합니다. 마지막 틱 승/무/패 +1/0/−1에 매 틱 β(γΦ다음 − Φ현재)를 더하며 Φ는 학생 관점 점령 격차/전체 칸 수, 종료 상태 Φ는 0, β 기본값은 0.25입니다. 할인된 shaping 합이 초기 상태에 따른 상수이므로 이 항은 중간 신호를 주되 최종 목표를 바꾸지 않습니다. 사전학습 시 개인 점령 보상은 이 단계에서 사용하지 않습니다. PPO·GAE 업데이트와 행동 마스킹은 기존 학습기를 공유합니다.
4. 20업데이트마다 두 봇을 별도 고정 검증 시드로 평가합니다. 각 정책·상대 조합 20경기, 양 진영 절반씩입니다. 두 상대 중 낮은 승률이 높은 체크포인트를 best.pt에 보관합니다. 동률이면 승률 합계, 그것도 같으면 먼저 나온 체크포인트입니다. latest.pt에는 재개 상태를 보관합니다.

## 결과

- plots는 result/learning번호/training.png에 구조·시드별 고정 봇 PPO actor/critic 손실과 검증 승률을 그립니다. 자기대전 및 고정 봇 단계 원자료는 각각 pretraining.csv와 training.csv입니다.
- evaluate는 사전학습 직후와 검증에서 선정된 모델을 동일한 미사용 평가 시드로 비교합니다. 각 학습 진영 정책·상대마다 40경기, 실제 진영별 20경기입니다. 구조·시드·체크포인트당 봇별 합계 80경기입니다. 마지막 시점끼리 비교하려면 evaluate 뒤에 --checkpoint latest.pt를 붙입니다.
- result/evaluation번호/win_rates.csv에 시드별 및 전체 승무패, 승률, 변화(%p), 최종 점령 격차를 저장하고 win_rates.png에 구조별 합산 승률을 그립니다. sources.json에서 개별 경기 CSV 위치를 확인하세요. 두 봇 각각의 승률로 80% 달성을 판단하세요. --trace-all을 붙이면 틱별 JSON과 협력 지표도 저장합니다. 기존 평가기의 per_agent_return은 공통 비교용 점유율·점령 지표이며, 고정 봇 PPO의 학습 보상과 구분됩니다.
