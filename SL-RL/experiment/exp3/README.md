# exp3 · AE 마스킹과 잠재 차원

저장소 루트에서 `rlTeam`을 활성화한 CMD 또는 PowerShell로 한 줄을 실행합니다.

```text
python -B SL-RL/experiment/exp3/launch.py
```

원래 터미널이 기준 결과를 확인하고 신규 인코더 8개를 준비합니다. 인코더는 조건별로 1대1과 3대3에서 하나씩 학습해 세 PPO 시드가 공유합니다. 준비가 끝나면 Windows 콘솔 세 개가 열리고, 각 콘솔이 시드 하나(7·19·31)를 맡습니다. 콘솔 하나에서 8개 run을 순서대로 학습합니다. 전체 진행이 끝날 때까지 원래 터미널을 열어 두세요.

| 사전학습에서 가린 칸 | 잠재 8 | 잠재 16 | 잠재 32 |
|---|---|---|---|
| 0칸 | 신규 `mask00_z8` | exp2 복사 `mask00_z16` | 신규 `mask00_z32` |
| 9칸 | 신규 `mask09_z8` | exp1 복사 `mask09_z16` | 신규 `mask09_z32` |

각 칸에는 1대1·3대3 × 시드 3개로 6개 run이 있습니다. 총 36개 중 12개를 재사용하고 **24개를 새로 학습**합니다. 신규 PPO 예산은 24 × 400업데이트 × 8경기 = **76,800경기**입니다. 사전학습과 검증 경기는 이 합계에서 제외했습니다. [공통 설정](config.toml) · [복사 출처와 내용](COPIED_FROM.md)

## 비교 조건

- 3×10 지도이므로 9칸은 정확히 30%입니다. 양성 마스킹 조건은 매 표본에서 서로 다른 9칸을 균일하게 골라 가리고 그 9칸의 복원 손실을 계산합니다. 0칸 조건은 30칸 모두를 복원합니다. 두 방식의 인코더 복원 정확도는 채점 대상도 함께 표시해서 읽으세요.
- 인원마다 사전학습용 봇 경기 160개(학습 128, 검증 32), 경기당 12시점, 시드 8101과 30에포크를 사용합니다. 같은 인원에서는 지도 수집 시드·경기 단위 분할이 같고, 9칸 조건끼리는 검증 마스크도 같습니다. PPO에는 전체 지도를 입력하고 인코더를 고정합니다.
- 1대1·3대3 자기대전 모두 최대 64틱, 보상 계수 α=1입니다. 신규 run의 학습 중 검증은 같은 인원끼리 20업데이트마다 하며, 최고·최신 체크포인트를 보관합니다.
- 모든 조건의 최종 평가는 **업데이트 400, 3대3**입니다. 고정 상대 5종과 같은 평가 시드·진영 배치를 사용하며, 복제 팀과 직접 팀 맞대결은 마스킹 칸 수·잠재 차원·학습 시드가 같은 run만 사용합니다. exp1과 exp2의 과거 저장·검증 방식 차이는 복사 출처 문서에 기재했습니다.

## 저장과 재개

- **신규** 학습은 `exp3/run1`, `run2`, …에 저장됩니다. 병렬 실행 순서에 따라 번호가 달라지므로 `settings.json`의 `ssl.latent`, `ssl.mask_fraction`(둘 다 `config` 아래), `size`, `seed`를 확인하세요.
- **복사**한 run은 `exp3/copied/exp1/run*`과 `exp3/copied/exp2/run*` 아래에서 원본 번호를 유지합니다. 평가표·리플레이에 적힌 run 번호와 상대경로가 그대로 연결됩니다. 해당 16차원 모델은 일괄 학습에서 건너뜁니다.
- 중단 시 첫 줄의 일괄 명령을 다시 실행합니다. 완료된 인코더와 기존 run을 찾아 `latest.pt`에서 이어가며 완료한 run에는 경기를 추가하지 않습니다. 첫 저장 전에 중단한 run은 같은 설정·시드로 해당 폴더에서 다시 시작합니다.
- `--plan`은 계획만 출력합니다. `--import-only`는 16차원 복사본의 준비·해시 검사만 수행합니다. 다음 비교에서 과거 실험과 다른 예산·시드를 사용하려면 별도 실험 폴더를 쓰고 `ae_grid.reuse_latent16 = false`로 설정하세요.

## 평가·비교표·리플레이

일괄 학습이 끝난 다음 아래 순서로 실행합니다.

```text
python -B SL-RL/analysis.py plots --experiment exp3
python -B SL-RL/analysis.py evaluate --experiment exp3
python -B SL-RL/analysis.py report --experiment exp3
python -B SL-RL/analysis.py replays --experiment exp3
```

각 조건의 그림·보고서·GIF는 `exp3/result/analysis_u0400/mask00_z8/` 등으로 나뉩니다. `report`는 상위 폴더에 `grid_평가시드_경기수_상대목록.csv`도 만듭니다. 조건·출처·학습 인원·상대별로 세 시드 각각과 합계(`seed=all`)를 담습니다. `duel_1v3`는 1대1 복제 팀 관점입니다. 완료된 기준 평가가 같은 조건이면 재사용합니다. 전체 원자료의 출처를 보존하기 위해 복사된 과거 결과는 `copied/` 아래, 새 보고서는 `result/` 아래에 둡니다.

단일 조건은 어느 단계에서나 예를 들어 `--condition mask09_z16`으로 선택합니다. 기준 결과는 새 학습 전에도 볼 수 있습니다. `--runs run1 run2`를 지정할 때는 번호가 속한 `--condition`도 함께 지정하세요. 개별 체크포인트 평가는 예를 들어 `python -B SL-RL/run.py evaluate --experiment exp3 --condition mask09_z16 --run run1 --checkpoint latest.pt`로 실행합니다.

세 콘솔의 축소 검증은 `python -B SL-RL/experiment/exp3/verify.py`로 재현할 수 있습니다. 최대 4틱·2업데이트 임시 실험에서 신규 24개 조합, 이어학습, 같은 조건끼리의 평가 및 비교표를 검사합니다.
