# 순차 모델 설계 합의

향후 저장소 루트에 SL-RL과 나란한 새 모델 폴더를 둔다. modelB는 제안 이름이며 이 문서는 설계 기록이다.

- 3대3 raw 자기대전. 양 팀은 별도 actor·critic을 학습하고 각 팀의 세 명은 가중치를 공유한다.
- actor는 자기 순번과 같은 틱에 앞 순번 아군이 확정한 행동을 받는다. critic 입력은 기존 독립 모델과 동일하게 둔다.
- 고정 ID 순으로 환경 세션에 제출하고 여섯 행동이 모이면 물리 상태를 한 번 진행한다. 미공개와 확정 정지를 구별하고 상대 행동은 숨긴다. PPO에는 당시 공개된 조건을 저장하며 보상·GAE는 틱 단위다.
- 3×10, 64틱, 자기 팀 점유율 + 개인 점령 기여(α=1), 시드 7·19·31 각각 3,200경기. 같은 시드 exp2 raw 3대3 독립 팀, 1대1 복제 팀 및 고정 봇 5종과 양 진영에서 평가한다.
- 추가 검토 후보는 순번을 유지한 채 앞선 행동만 가리는 평가다.

근거는 [팀 문헌](../docs/RL_Algorithm_Literature_Notes.tex), [환경 명세](../env.md)와 [환경 세션](../territory_rl/session.py)이다.
