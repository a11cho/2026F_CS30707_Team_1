# Territory Control에서 행동 제안 공유와 역전파가 협력에 미치는 영향

## 요약

3대3 Territory Control에서 아군의 1차 행동 제안을 최종 행동 선택에 사용하는 Feedback PPO를 비교하였다. 팀원 제안을 공개하고 수신자에서 송신자로 이어지는 역전파만 끄고 학습하면, 기존 공유 모델보다 전체 경기 점수가 **19.40%에서 24.61%**로, 엄호 성공률이 **13.19%에서 43.84%**로 높아졌다. 처음부터 팀원 제안을 가린 모델의 경기 점수는 세 학습 조건 중 가장 높은 **26.95%**였다.

역전파를 끈 모델은 평가 때 팀원 제안을 공개하면 가렸을 때보다 경기 점수가 **1.82%p**, 엄호 성공률이 **14.40%p** 높았다. 동일 상태에서 재실행한 결과, 역전파를 끈 모델의 엄호 증가분 275건 중 228건은 두 모델 모두 팀원 제안을 가렸을 때도 남았고, 47건은 제안 공개 효과의 차이였다.

## 실험 설정

### 환경과 정책

환경은 `territory_control`의 `feedback` 전략으로 실행하였다. 두 팀이 각각 세 에이전트를 사용하며, 보드는 8×8, 최대 경기 길이는 128틱, 초기 배치는 전선, 부활 대기는 0틱이다. 관측은 회전을 끈 15×15 `tilemap`과 에이전트 상태 및 합법 행동 마스크를 사용한다. 정책은 관측에서 맵과 에이전트 위치를 복원하며, CNN의 공간 입력은 8×10으로 패딩한다. [환경 및 관측 계약](../README.md)

학습 팀의 세 에이전트는 CNN과 행동 헤드의 가중치를 공유한다. 각 에이전트가 먼저 9개 행동 중 하나를 이산 제안으로 제출한 다음, 같은 상태에서 자기 제안과 공개된 팀원 제안을 입력으로 받아 최종 행동을 선택한다. 최종 제출이 끝나면 환경이 한 틱 진행한다. 팀원 제안 가림은 자기 제안만 남기는 방식이다. PPO 확률비에는 기록한 1차 제안과 2차 행동의 로그 확률 합을 사용한다.

| 학습 조건 | 최종 행동 헤드의 제안 입력 | 수신자 손실에서 팀원 제안으로의 역전파 |
| --- | --- | --- |
| 공유·역전파 켬 | 자기 제안과 팀원 2명의 제안 | 순전파에 이산 제안을 쓰고, 송신자의 제안 확률을 통해 straight-through gradient 전달 |
| 공유·역전파 끔 | 자기 제안과 팀원 2명의 제안 | 수집한 이산 제안을 고정 입력으로 사용해 이 경로를 차단 |
| 가림 학습 | 자기 제안 | 팀원 슬롯을 가려 해당 경로가 비활성화됨 |

모든 조건에서 자기 제안과 최종 행동은 PPO로 학습한다. 제안 하나로 그 송신자의 최종 행동을 예측하는 교차 엔트로피 보조 손실도 모든 조건에서 가중치 0.1로 유지하였다. 공유·역전파 끔 조건에서도 수신자의 메시지 임베딩과 최종 행동 헤드는 학습된다.

| 항목 | 공통 설정 |
| --- | --- |
| 학습량 및 초기화 | 학습 시드 7·19·31 각각 8개 환경 × 64틱 × 196 업데이트 = 100,352 환경 틱. 같은 시드의 세 조건은 초기 가중치가 동일하다. |
| 학습 상대 | 에피소드마다 `random`과 `expand`를 균등하게 선택하며, 학습 팀의 진영은 에피소드가 끝날 때마다 교대한다. |
| 팀 보상 | 전이 직후의 아군·적 영역 칸 수 차이를 8,192로 나눈 값에 경기 종료 보상을 더한다. 종료 보상은 승리 +1, 무승부 0, 패배 −1이다. |
| PPO | Adam 학습률 0.0003, 할인율 0.995, GAE λ 0.95, clip 0.2, 업데이트당 4 에폭, 미니배치 256 에이전트 샘플, 가치 손실 가중치 0.5, 엔트로피 가중치 0.01, 최대 그래디언트 노름 0.5 |
| 경기 평가 | 업데이트 196의 `latest.pt`로 마스킹한 행동 분포의 최댓값을 선택한다. 상대 `random`, `expand`, `aggressive`, `defend`에 대해 평가 시드 681000–681015를 두 진영에서 사용한다. 조건당 학습 시드별 128경기, 합계 384경기다. |

### 지표와 동일 상태 재실행

- **경기 점수**는 `(승리 수 + 0.5 × 무승부 수) / 경기 수`이다. 행동 지표는 성공 건수를 해당 기회 수로 나누고, 표에는 분자와 분모를 함께 제시한다.
- **엄호**는 아군이 서 있는 타일이 실제로 공격받고, 공격 가능한 인접 아군 수가 적 공격 수 이상인 경우를 기회로 센다. 타일을 지키고 위협받은 아군이 공격과 이동을 거쳐 생존해야 성공이다. 사망 후 즉시 부활한 경우에도 사망 이벤트를 기록해 실패로 센다.
- **연쇄 이동 양보**는 전선의 아군이 비킬 수 있는 상황에서 앞뒤의 아군이 모두 안전하게 이동하고, 뒤의 아군이 앞선 아군의 원래 타일에 진입한 경우다. 앞선 아군을 정지로 바꾼 재실행에서 그 진입이 실패해야 성공으로 센다.
- **같은 칸 제안 양보**는 두 명 이상이 같은 빈 아군 타일을 제안했고 서로 다른 안전한 이동 경로가 있는 상황에서 측정한다. 최종 행동으로 제안자들이 모두 안전하게 이동하고 그중 한 명이 제안한 칸에 도달하며, 서로 충돌하는 1차 제안을 그대로 실행하면 같은 성공이 재현되지 않아야 한다.

학습 조건을 동일한 상태에서 비교할 때는 공유·역전파 켬과 가림 학습 모델의 전체 경기 궤적을 사용하였다. 각 학습 시드·평가 상대·대전 시드·진영 조합에서 짧은 궤적의 길이만큼 두 궤적에서 각각 비복원 추출하여, 모델당 29,867틱씩 **59,734틱**을 구성하였다. 추출 시드는 911001이다. 각 상태에서 원래 상대의 행동을 고정하고 한 틱을 재실행했으며, 엄호 기회 3,274건은 모든 조건에 공통이다. 평가 시 제안 공개의 효과를 측정할 때는 체크포인트와 1차 제안도 고정하였다. 최종 행동 정책을 비교하는 추가 대조에서는 두 공유 모델에 같은 1차 제안까지 공급하였다. ## 해석

1. **팀원 제안의 공개와 팀원 제안으로 전달되는 역전파는 별개의 개입이다.** 공개 상태의 두 공유 모델을 비교하면 역전파를 끈 모델이 동일 상태에서 엄호에 275건 더 성공했다. 이 차이 중 228건(83%)은 두 모델에서 팀원 제안을 함께 가렸을 때 남았고, 47건은 평가 시 공개 효과의 차이였다. 두 모델에 역전파 켬 모델의 동일한 1차 제안을 공급하고 팀원 제안을 가린 경우에도 역전파 끔 모델이 404건, 역전파 켬 모델이 221건을 성공했다. 최종 행동을 고르는 학습된 정책에도 차이가 생겼음을 보여 준다. [제안 가림과 동일 1차 제안 대조](../runs/communication-tilemap-20261126/no-message-backprop-ablation-comparison.json)
2. **역전파를 끈 공유 모델에서 제안은 엄호에 추가로 기여했다.** 동일 상태에서 두 번째 행동을 고를 때 팀원 제안을 공개하면 엄호 성공이 449건에서 517건으로 늘었다. 전체 경기 평가에서도 공개 상태의 점수와 엄호율이 높았다. 이동에서는 연쇄 양보율이 2.57%와 2.59%로 비슷했고, 같은 칸 제안 양보는 관측 사례가 드물었다.
3. **경기 성과와 협력 지표의 순위는 지표와 평가 방식에 따라 달랐다.** 전체 경기에서 가림 학습 조건의 경기 점수가 가장 높았다. 역전파를 끈 공유 모델은 가림 학습 모델과 엄호율이 1.12%p 차이였고, 동일 상태에서는 15.36%p 차이였다. 공개 여부와 학습 조건에 따라 실제 경기 중 만나는 상태와 엄호 기회의 분포가 달라졌다.

## 한계

- **학습 반복과 시드 편차.** 결과는 학습 시드 3개의 기술통계다. 역전파를 끈 뒤 전체 경기에서 성공한 엄호 1,078건 중 962건이 시드 31에서 나왔고, 동일 상태 엄호는 시드 19에서 감소했다. 같은 경기 안의 틱과 같은 체크포인트의 관측은 상관되므로, 기회 수를 독립적인 학습 반복 수로 해석하기 어렵다.
- **전체 경기 지표와 기회 분포.** 공개·가림 조건은 같은 시작 시드를 사용하지만 생성하는 궤적이 달라진다. 시드 31에서 엄호 성공이 481건 차이 나는 데에는 기회 수 540건 차이도 포함된다. 이 비교의 엄호율은 각 정책이 실제로 만난 기회에 조건부인 비율이다.
- **재실행의 범위.** 혼합 상태는 기존 공유·역전파 켬 모델과 가림 학습 모델의 방문 상태에서 추출하였다. 역전파 끔 모델의 독자적인 방문 상태나 장기 반응은 전체 경기 결과가 다룬다. 동일 상태 재실행은 상대 행동을 고정한 한 틱의 효과를 측정하므로 이후 상대 반응과 누적 승패에 대한 해석 범위가 제한된다.
- **희소한 이동 충돌 기회.** 역전파를 끈 모델은 공개 평가에서 같은 칸 양보가 2/32건, 가림 평가에서 0/28건이었다. 이 수치로 일반적인 충돌 양보 능력의 우열을 판단하기는 어렵다. 평가에서 가장 큰 점수 차이는 `random` 상대에서 나왔고 강한 두 상대에서 승리는 0건이었다.
- **통신과 경사 경로의 범위.** 이 실험의 메시지는 이번 틱에 제출하는 이산 행동 제안이다. 역전파의 효과는 송신자 예측 보조 손실과 팀 보상을 유지한 이 정책 구조에서 측정하였다.
